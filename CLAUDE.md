# Agent rules

## Git
- After making changes, stage the files you changed with `git add <paths>`. Stage only your own changes, never unrelated edits already in the working tree.
- Then give the user a ready-to-use commit message: a short summary line, a blank line, and brief bullets for the details.
- Never run `git commit` (or amend, rebase, push, or anything else that creates or rewrites commits). The user commits themselves.
